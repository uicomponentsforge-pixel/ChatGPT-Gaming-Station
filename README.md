# 🎮 ChatGPT Gaming Station — Premium Edition

Welcome to **ChatGPT Gaming Station**, a feature-packed web-based arcade and gaming hub built using modern HTML5, CSS3, and vanilla JavaScript.

---

## 🌟 Overview

ChatGPT Gaming Station is a browser gaming portal featuring a selection of mini-games, an XP and level progression system, virtual coin currency, customizable shop, achievements, leaderboard, Web Audio sound effects, and persistent local storage.

---

## ✨ Features

- **🎮 12 Interactive Mini-Games**:
  - ⚔️ **Battle Arena**: Turn-based combat against AI enemies with attack, heavy attack, and healing options.
  - 🧩 **Puzzle Zone**: Test math skills and brainpower.
  - 🚀 **Space Explorer**: Expedition missions managing energy reserves.
  - 🏎️ **Racing Station**: High-octane speed tapping race.
  - 🏹 **Archer Quest**: Precision target shooting game.
  - 🧱 **Block Breaker**: Grid block destruction challenge.
  - 🐍 **Snake Galaxy**: Star collecting navigation game.
  - 🧠 **Memory Master**: Sequence recall memory puzzle.
  - 🪐 **Planet Defender**: Wave defense survival game.
  - ⚡ **Reaction Rush**: Quick-reflex response test.
  - 🏀 **Basketball Challenge**: Timing-based basketball shooting.
  - 🧟 **Zombie Survival**: Multi-wave survival challenge.

- **⭐ XP & Leveling System**: Earn XP by playing and winning games to level up your player profile.
- **🪙 Coin Shop**: Earn coins from game rewards and unlock avatars, boosts, badges, and skins.
- **🏆 Achievements**: Unlock special badges and bonuses by reaching game milestones.
- **🥇 Leaderboard**: Compare your progress and XP against top players.
- **🔊 Web Audio FX**: Synthesized sound effects built with the native Web Audio API.
- **💾 Auto-Save**: Player progress, XP, coins, and unlocked items persist automatically via `localStorage`.

## 🚀 Getting Started

No build tools or backend dependencies are required! You can run ChatGPT Gaming Station directly in any modern web browser.

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Choose a game and start playing!

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and page views.
- **CSS3**: Custom CSS variables, Flexbox, Grid, keyframe animations, responsive design.
- **JavaScript (ES6+)**: Modular functions, DOM manipulation, Web Audio API, `localStorage` integration.
